Try any scenario's commit graph right here in the browser — no `npm install` needed.
The graphs are built from real hashes captured at build time: every short hash you see
is exactly the one you'll get locally when you call `spinUpScenario('name')`.

<ScenarioPlayground />

## How it works

Each scenario's `setup()` function is run at build time in a temporary git repository.
The resulting `git log --all --date-order` output is captured as structured data and
stored in `scenarios.json` alongside the existing ASCII graph. The playground reads that
data in the browser and renders the DAG with a lane-layout algorithm.

## Tips

- **Search** the sidebar to filter by name, kind, or tag.
- **Kind pills** narrow the list to a single scenario family.
- **Hover a commit node** to see its full hash, refs, subject, author, and parents.
- **Click a commit node** to copy the full hash to your clipboard.
- **Deep-link** to any scenario with `#scenario=<name>` in the URL — bookmarkable and shareable.
