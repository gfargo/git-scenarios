This directory holds Simplified Chinese (`zh-cn`) translations of the docs.

Mirror the path of the English page you're translating, e.g. the
Chinese version of `docs/docs/introduction.md` goes at
`docs/zh-cn/introduction.md`.

Until a page is translated, Starlight automatically falls back to
the English content for that route (with an untranslated-page
notice), so this directory does not need to be fully populated for
the site to build or for `zh-cn` routes to work.

See https://starlight.astro.build/guides/i18n/ for details.
